Claudex Setup & Operating Guide

Safely connect Claude Code to OpenAI Codex and Google Antigravity models while bridging Cursor Agent through isolated MCP tools.

1. Bootstrap & Setup

Get started on Windows, macOS, Linux, or WSL in seconds.

🪟

Windows (PowerShell)

Installs native executable shims and configures per-user local environment without requiring Admin access.

PowerShell
.\install.ps1
🐧 / 🍎

macOS / Linux / WSL

Verifies Node baseline, extracts authenticated CLIProxyAPI releases, and sets up path wrappers.

Bash / Zsh
./install.sh

Running Setup Directly

Initialize or update managed binaries, configuration, and launch gateway service on 127.0.0.1:8317:

Terminal
claudexctl setup

2. Provider Authentication

Authenticate OpenAI Codex or Google Antigravity OAuth through CLIProxyAPI.

🧠

Codex OAuth

Initiate browser-based or device-code login for OpenAI Codex models.

Terminal
claudexctl auth codex
🚀

Google Antigravity OAuth

Authenticate with Google Antigravity provider for Gemini and Claude models.

Terminal
claudexctl auth antigravity

3. Launching Claude Code

Run Claude Code with live-discovered models. Your global claude environment is never modified.

✨

Codex Launcher (claudex)

Launches Claude Code routed to live Codex provider models.

Terminal
claudex --model gpt-4o -- --print "Hello"
⚡

Antigravity Launcher (claude-agy)

Launches Claude Code routed to live Antigravity models.

Terminal
claude-agy --model gemini-1.5-pro -- --verbose

4. Cursor Agent MCP Bridge

Expose Cursor Agent tools to Claude Code with safety boundaries.

Read-Only Tools

cursor_ask and cursor_plan execute in disposable, isolated snapshots without touching your working repo.

Write Safety

Write operations require explicit persistent opt-in plus 1-time 5-minute interactive TTY approvals bound to exact commit & SHA-256 digest.

Terminal - Enable Cursor Writes & Approve
claudexctl cursor writes enable --yes
claudexctl cursor approve <APPROVAL_ID>
