Claudey Complete Setup & Manual

A step-by-step guide for absolute beginners: From installing Node.js, Git, and Claude Code to configuring Codex & Antigravity models.

Step 0: Install Required Prerequisites (For New Systems)

If your system is completely fresh, follow these steps to install Node.js, Git, and Claude Code first.

1️⃣

1. Install Node.js 22+

Method A: If winget is available on your Windows:

PowerShell
winget install OpenJS.NodeJS.LTS
⚡ No winget? Use Direct PowerShell Installer (Method B):
PowerShell (Direct Auto-Install)
Invoke-WebRequest -Uri "https://nodejs.org/dist/v22.20.0/node-v22.20.0-x64.msi" -OutFile "$env:TEMP\node.msi"; Start-Process msiexec.exe -ArgumentList "/i $env:TEMP\node.msi /passive" -Wait
Or download directly from: nodejs.org/en/download
✓ Verify: node --version (Must be ≥ 22.20.0)
2️⃣

2. Install Git

Method A (winget):

PowerShell
winget install Git.Git
⚡ No winget? Download Official Git Installer:
Download directly from: git-scm.com/download/win
✓ Verify: git --version
3️⃣

3. Install Claude Code

Install official Claude Code CLI tool globally via npm:

PowerShell
npm install -g @anthropic-ai/claude-code
✓ Verify: claude --version (Must be ≥ 2.1.229)

Step 1: Clone Repository & Run Claudey Setup

Download Claudey and run the automated setup command.

📥

1. Clone Repository

Terminal
git clone https://github.com/ramsaijanapana/claude_code_cliProxy.git
cd claude_code_cliProxy
⚙️

2. Run Setup Script

Run bootstrap script or setup command to install binary and start loopback gateway:

Windows / POSIX
.\install.ps1 # Windows
./install.sh # macOS / Linux

Step 2: Provider OAuth Login

Authenticate with OpenAI Codex or Google Antigravity.

🧠

Codex OAuth Login

Launches browser OAuth callback or device code flow for OpenAI Codex access:

Terminal
claudey auth codex
🚀

Google Antigravity OAuth Login

Launches browser OAuth callback for Google Antigravity models:

Terminal

Step 3: Launch Claude Code

Launch via Antigravity (claude-agy)

Terminal

Step 6: FAQ & Troubleshooting

Solutions for common beginner issues.

Q: What if 'winget' is not recognized on Windows?
Use the 1-line PowerShell auto-installer provided in Step 0 (Method B) or download the MSI directly from nodejs.org.
Q: PowerShell script execution is disabled on Windows?
Run Set-ExecutionPolicy -Scope Process Bypass in your PowerShell window before running .\install.ps1.
Q: Error: PORT_IN_USE (Port 8317 is occupied)?
Run claudey config set port 8320 --yes or specify a custom port during setup: claudey setup --port 8320.
Q: Does Claudey alter my system 'claude' command?
No! Claudey installs only claudey, claude-codex, claude-agy, and claude-grok. Your existing claude executable and configuration remain completely untouched.
