Claudex Complete Setup & Manual

A step-by-step guide for absolute beginners: From installing Node.js, Git, and Claude Code to configuring Codex & Antigravity models.

Step 0: Install Required Prerequisites (For New Systems)

If your system is completely fresh, follow these steps to install Node.js, Git, and Claude Code first.

1️⃣

1. Install Node.js 22+

Run Windows Package Manager command in PowerShell:

PowerShell
winget install OpenJS.NodeJS.LTS
✓ Verify: node --version (Must be ≥ 22.20.0)
2️⃣

2. Install Git

Install Git for version control and repository management:

PowerShell
winget install Git.Git
✓ Verify: git --version
3️⃣

3. Install Claude Code

Install the official Claude Code CLI tool globally via npm:

PowerShell
npm install -g @anthropic-ai/claude-code
✓ Verify: claude --version (Must be ≥ 2.1.229)
🍺

1. Install Node.js & Git via Homebrew

Terminal
brew install node git
✓ Verify: node -v & git -v
🤖

2. Install Claude Code

Terminal
npm install -g @anthropic-ai/claude-code
✓ Verify: claude --version
🐧

1. Install Node.js 22 & Git (Ubuntu/Debian)

Bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt install -y nodejs git tar
✓ Verify: node -v & git -v
🤖

2. Install Claude Code

Bash
sudo npm install -g @anthropic-ai/claude-code
✓ Verify: claude --version

Step 1: Clone Repository & Run Claudex Setup

Download Claudex and run the automated setup command.

📥

1. Clone Repository

Terminal
git clone https://github.com/ramsaijanapana/claude_code_cliProxy.git
cd claude_code_cliProxy
⚙️

2. Run Setup Script

Run bootstrap script or setup command to install binary and start loopback gateway:

Windows / POSIX
.\install.ps1 # Windows
./install.sh # macOS / Linux

Step 2: Provider OAuth Login

Authenticate with OpenAI Codex or Google Antigravity.

🧠

Codex OAuth Login

Launches browser OAuth callback or device code flow for OpenAI Codex access:

Terminal
claudexctl auth codex
🚀

Google Antigravity OAuth Login

Launches browser OAuth callback for Google Antigravity models:

Terminal
claudexctl auth antigravity

Step 3: Launch Claude Code

Launch Claude Code against live discovered models without altering your normal system claude executable.

✨

Launch via Codex (claudex)

Terminal
claudex
claudex --model gpt-4o -- --verbose
⚡

Launch via Antigravity (claude-agy)

Terminal
claude-agy
claude-agy --model gemini-1.5-pro

Step 4: Optional Cursor Agent MCP Integration

Expose Cursor Agent tools safely to Claude Code.

1. Enable Plugin & Login

Terminal
claudexctl setup --with-cursor
claudexctl cursor login

2. Write Safety & Approvals

Terminal
claudexctl cursor writes enable --yes
claudexctl cursor approve <APPROVAL_ID>

Step 6: FAQ & Troubleshooting

Solutions for common beginner issues.

Q: PowerShell script execution is disabled on Windows?
Run Set-ExecutionPolicy -Scope Process Bypass in your PowerShell window before running .\install.ps1.
Q: Error: PORT_IN_USE (Port 8317 is occupied)?
Run claudexctl config set port 8320 --yes or specify a custom port during setup: claudexctl setup --port 8320.
Q: Does Claudex alter my system 'claude' command?
No! Claudex installs only claudexctl, claudex, and claude-agy. Your existing claude executable and configuration remain completely untouched.
